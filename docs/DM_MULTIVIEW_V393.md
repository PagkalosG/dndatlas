# v3.9.3 — single-campaign DM Multiview pilot
Access: authenticated current Creator/Admin and DM only. No Co-DM. Uses the current D1 authorized roster and existing 30-second revision polling (when idle, no active edit, and visible); no new endpoints or database migration. Does not alter privacy projections.
Cards and compact table show HP, temp HP, AC, initiative bonus, passive perception, Hit Dice, spell slots and conditions; cards add speed, individual spell slot levels and expandable class resources. Filter and sort locally. Initiative bonus sorting is not encounter turn order.
Per-character damage/healing uses the existing versioned save path with explicit character ID, account and revision checks; consumes temp HP first and caps healing. No auto death saves, resistance, condition or concentration handling. DM confirms final adjusted damage. Full sheet and combat links retain existing flows. No dice rolling, encounter tracking, batch rests or campaign isolation in this pilot.
