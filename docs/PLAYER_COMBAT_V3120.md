# v3.12.0 — player combat integration and Save improvements
Players propose actions or request End Turn on the last saved active encounter. A separate authenticated inbox accepts batches only through global Save, validates ownership and current turn, permits reactions outside the player's turn, and deduplicates stable UUIDs. The DM reviews proposals locally, saving decisions with the encounter revision; approved actions are log-only (no automatic damage or resource expenditure), and approved current-turn End Turn advances the encounter. The private state, enemy HP and notes remain server-side. Player proposals are visible only to their owner and privileged users. An existing active encounter needs explicit Enable and Save before submissions. The polling cadence remains 30 seconds; dirty sheets are not replaced, but inbox and public turn can refresh independently. The Save badge counts dirty sheets, encounter, pending operations and proposals, tooltip shows last successful save. Exports include unsent proposals; no unencrypted private browser persistence. Existing sheet writes use existing server validation and revisions; a cross-entity atomic batch and guided merge/recovery remain deferred. No digital rolls. No automatic HP/resource deductions for proposals.
