# v3.15.0 — Monster library and encounter builder

Cumulative release based on v3.14.0 and v3.13.0; current production main is v3.12.0. Deploy the compatible production Worker first, then the frontend. No new D1 tables, bindings, or migration.

DM/Creator → Multiview → Battle View → Monster Library. Search by name, exact CR, creature type or size; browse 30 results at a time. The offline library contains 330 normalized creature entries from SRD 5.2.1 (not the proprietary complete Monster Manual). Stat blocks are rendered as escaped plain text with AC, HP, CR/XP, ability scores/saves, speeds, traits, actions, immunities and resistances as provided by the source. Source stat blocks retain English text; navigation is bilingual. Use physical dice or the printed Initiative Score. Batch-add copies with shared final initiative; each has independent HP and existing condition/log controls. During setup, leave initiative blank and fill later. When adding during combat, use arrows to set correct order manually.

XP calculator sums individual player-level budgets and enemy stat-block XP without the 2014 multiplier. Missing monster XP is flagged; custom CR uses standard XP. Printed SRD 5.2.1 Archmage 8,000 XP is retained despite the usual CR 12 budget of 8,400; lair-specific XP alternatives are visible in stat-block text but not included in default budget. The calculator estimates difficulty, not a guaranteed combat outcome. Generic enemies created through the older Add Combatant tool have unknown XP.

Custom monster definitions and reusable enemy compositions are private DM/Creator data in the same revisioned encounter envelope. Save a template from a composition of library enemies; load into an empty/new encounter or append to an encounter in setup. Loading resets HP, initiative and out state; active combat is not overwritten. Templates do not contain character sheets. Deleting an encounter retains the library and templates. Existing encounter and template snapshots retain custom metadata if a definition is edited/deleted. Limits: 40 custom monsters, 20 templates, 60 combatants, 2,000 characters per custom block, and 1.5 MB total stored JSON to stay below D1 row limits. All writes only through global Save; no dice UI. Verify staging and mobile UI before deploying.
