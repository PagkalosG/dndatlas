# Έκδοση v3.0 — τι υλοποιείται και τι απαιτεί επαλήθευση

## Υλοποιημένο στο πακέτο

- Έξι καρτέλες, νέο Overview, Subclass μόνο σε κατάλληλο επίπεδο, διακριτά Rest buttons με εικονίδια, σύνοψη Feats/Features.
- Κοινός χαρακτήρας μέσω D1 μετά τη σύνδεση, Player/DM/Creator ρόλοι, Creator-only PIN management, backup recovery codes, optimistic revision check.
- Ιδιωτική ιστορία server-side (ιδιοκτήτης και DM), επιλογή κοινοποίησης από τον παίκτη.
- Όπλα ξεχωριστά στον Εξοπλισμό, επιλογές Weapon Mastery από παίκτη, αναλώσιμα με κοινές ποσότητες Combat/Inventory. Healing Potion: χειροκίνητη εισαγωγή πραγματικής ζαριάς 2d4+2. Προαιρετικά, DM-verified consumable effects: θεραπεία, προσωρινά HP και αλλαγές καταστάσεων.
- Gallery από Cloudflare Drive Worker με προτεινόμενο image streaming endpoint· tags ανά session μέσω D1.
- Προετοιμασία εξαγωγής στα πραγματικά συμπληρώσιμα πεδία του επίσημου 2024 PDF.

## Χρειάζεται επιπλέον έλεγχος

- Πρώτη πραγματική εγκατάσταση / δοκιμή Cloudflare Workers & D1 στον λογαριασμό σου (δεν έχουμε credentials).
- Browser PDF export: λειτουργία μέσω pdf-lib CDN, μερική αντιστοίχιση fields, πολλά ονόματα/spells μπορεί να υπερβαίνουν τον διαθέσιμο χώρο. Δεν έχει επαληθευτεί πλήρης οπτική πιστότητα για κάθε χαρακτήρα.
- Το Google Drive `/image/:id` απαιτεί αντικατάσταση του παλιού Worker· δεν έχει δοκιμαστεί στο πραγματικό Drive περιβάλλον σου.
- Ο πλήρης κατάλογος της Library και του Character Builder **δεν είναι ακόμη αυστηρά επαληθευμένος για όλα τα classes/levels/sourcebooks**. Το SRD 5.2.1 είναι η βάση πηγών· η υπάρχουσα βιβλιοθήκη διατηρεί συνοπτικές επεξηγήσεις.
- Οι ελληνικές/αγγλικές μεταφράσεις ορισμένων παλαιών popups χρειάζονται επιμέλεια.
- Πριν από οποιοδήποτε κοινό deployment απαιτείται JSON Backup και έλεγχος των 2024 Background ability bonuses από τον DM.
