# v3.11.0 — Manual Save and combat activity
Sheet edits, builder/import additions, DM stat edits, HP, combat turn and encounter state, log/history and staged image/session imports stay in memory until the global Save. Dirty state compares acknowledged character snapshots, so reverting edits disables Save. Save sends one request per dirty character, then encounter/history and queued shared edits; not a single cross-entity transaction. On partial failure, successful character writes remain acknowledged, unsaved changes are preserved; refresh/discard is explicit and stale revisions cannot be silently overwritten. Navigation/reload warning and draft JSON export are provided. No persistence of private unsaved state in browser storage. Authentication, account management, administrative destructive restore/delete/undo remain explicitly confirmed immediate operations, blocked when unsaved changes exist where applicable.
Combat log includes structured actor/target/round/turn, action type, outcome, final effective HP changes and optional resource/slot use. DM manual entries and direct HP edits from the loaded active encounter are tracked; no automatic player action ingestion, no effect adjudication. History retains up to 20 archived encounters / 1500 archived events, each encounter up to 500 events. End archives before clearing initiative/temporary participants; history has stats, JSON export, editable text recap for copy into Journal. Player combat banner is read-only and updates from saved state using existing 30-second polling; no hidden NPCs, HP, notes or history are exposed. No automatic End Turn submissions, automatic action tracker resets, timers or digital dice. Existing secure party backup does not include encounters.
