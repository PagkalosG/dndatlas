# D&D Atlas v2.1.2 — Οδηγίες για GitHub Pages

Το πακέτο περιέχει **ολόκληρη τη στατική εφαρμογή** και όχι μόνο ένα mockup. Οι έξι καρτέλες είναι Επισκόπηση, Χαρακτήρας, Μάχη, Εξοπλισμός, Ημερολόγιο και Βιβλιοθήκη. Μοναδικό ruleset: **D&D 5e (2024)**.

## Ανέβασμα

1. Πάρε **αντίγραφο JSON** των χαρακτήρων σου μέσα από την τωρινή εφαρμογή και κράτησε αντίγραφο του repository σου.
2. Αποσυμπίεσε το ZIP. Ανέβασε **όλα** τα περιεχόμενά του στη **ρίζα** του repository `dndatlas` (όχι μέσα σε νέο υποφάκελο).
3. Κάνε commit. Αν χρειάζεται, ενεργοποίησε **Settings → Pages → Deploy from branch → main / root**.
4. Άνοιξε `https://pagkalosg.github.io/dndatlas/`. Αν βλέπεις παλαιά έκδοση λόγω PWA, κάνε ανανέωση ή χρησιμοποίησε την επιλογή ενημέρωσης από τις Ρυθμίσεις.
5. Το `demo-party.json` περιέχει τους Borruk, Luna και Ammantyl. Στην πρώτη επίσκεψη χωρίς τοπικούς χαρακτήρες φορτώνεται αυτόματα εφόσον είναι διαθέσιμο. **Δεν αντικαθιστά** υπάρχοντες χαρακτήρες στον browser.

## Εικόνα χαρακτήρα

Από την **Επισκόπηση**, πάτησε την εικόνα. Επίλεξε αρχείο αν δεν υπάρχει, μετακίνησέ το μέσα στο κάδρο με ποντίκι ή δάχτυλο, άλλαξε τη μεγέθυνση από 100% έως 300%, και πάτησε **Αποθήκευση θέσης**. Η αλλαγή εφαρμόζεται **μόνο στην Επισκόπηση**. Δεν αλλοιώνεται η αρχική αποθηκευμένη φωτογραφία.

## Κοινά sessions και εικόνες από GitHub

### 1. Πρόσθεσε εικόνες

Ανέβασε εικόνες JPG, PNG, WebP ή GIF στον φάκελο `assets/campaign/`.

### 2. Ενημέρωσε τη λίστα εικόνων

Στο `data/campaign-images.json` πρόσθεσε:

```json
{
  "schema": 1,
  "images": [
    {"id":"old-map","title":"Χάρτης κάστρου","path":"assets/campaign/castle-map.jpg"},
    {"id":"battle","title":"Μάχη 1","path":"assets/campaign/battle-01.png"}
  ]
}
```

### 3. Πρόσθεσε το κοινό session

Στο `data/sessions.json`:

```json
{
  "schema": 1,
  "campaign": "Our Campaign",
  "sessions": [
    {
      "id": "session-01",
      "title": "Πρώτη συνεδρία",
      "date": "2026-10-17",
      "text": "Εδώ βάζω τι έγινε στη συνεδρία.",
      "images": ["assets/campaign/castle-map.jpg", "assets/campaign/battle-01.png"]
    }
  ]
}
```

Οι κοινές εικόνες εμφανίζονται σε **όλους** μετά το GitHub deployment. Το GitHub Pages δεν προσφέρει αυτόματα τη λίστα αρχείων ενός φακέλου: για τη συλλογή εικόνων πρέπει να ενημερώνεις το `campaign-images.json`.

Κάθε παίκτης μπορεί να προσθέσει προσωπικό session ή να τροποποιήσει/κρύψει κοινό session **μόνο στη δική του συσκευή**. Οι προσωπικές μεταβολές εξάγονται επίσης στο JSON backup. Δεν αλλάζει το αρχικό `sessions.json` στο GitHub. Η προσθήκη φωτογραφίας από συσκευή παραμένει τοπική μέχρι να ανεβάσεις το αρχείο στο GitHub.

## Σημαντικές διευκρινίσεις

- Στη **Μάχη**, τα ξόρκια εμφανίζονται μόνο σε χαρακτήρες με καταχωρισμένα ξόρκια, ενώ οι πολεμικοί ελιγμοί σε χαρακτήρες με τη σχετική δυνατότητα. Υπάρχει επιλογή «Ξόρκια μάχης / Όλα τα ξόρκια μου».
- Υπάρχουν αναλυτικές επεξηγήσεις για το πώς γίνονται οι επιθέσεις με πραγματικά ζάρια, **χωρίς ψηφιακό dice roller**.
- Ο Builder ανοίγει με το **+ Νέος χαρακτήρας**, όχι ως ξεχωριστή καρτέλα. Πλήρης αυτόματος έλεγχος κανόνων υπάρχει αυτή τη στιγμή κυρίως για Human / Fighter / Soldier επιπέδων 1–3. Τα υπόλοιπα χρειάζονται τεκμηριωμένο έλεγχο DM. Οι εισαγόμενοι χαρακτήρες μπορεί να περιέχουν εκκρεμότητες.
- Το PDF export προσφέρει προς το παρόν **εκτυπώσιμο φύλλο συμβατό με τους κανόνες 2024**, με αποθήκευση από τον browser ως PDF. **Δεν γεμίζει ακόμη το πραγματικό επίσημο PDF template της Wizards**.
- Οι περισσότερες οθόνες έχουν διεπαφή ΕΛ/EN. Ορισμένα προχωρημένα παλαιότερα παράθυρα ή ελεύθερες περιγραφές δεδομένων ενδέχεται να έχουν κείμενο διαφορετικής γλώσσας.
- Τα δεδομένα της συσκευής αποθηκεύονται τοπικά. Μην εκκαθαρίζεις τα δεδομένα ιστότοπου χωρίς **Export JSON backup**.

Δες και το αγγλικό `README.md` για επιπλέον τεχνικές λεπτομέρειες.

## Προαιρετικές εικόνες από Google Drive (v2.1)

Μπορείς να χρησιμοποιείς **έναν δημόσια κοινοποιημένο φάκελο Google Drive αντί να συντηρείς λίστα φωτογραφιών σε JSON**. Τα κοινά sessions παραμένουν στο `data/sessions.json` του GitHub.

1. Δημιούργησε έναν ξεχωριστό φάκελο Google Drive για **μη ευαίσθητες εικόνες campaign**. Επίλεξε κοινοποίηση «Οποιοσδήποτε έχει τον σύνδεσμο — Προβολή». Το περιεχόμενο αυτό μπορεί να γίνει δημόσια προσβάσιμο: μη βάζεις ιδιωτικές φωτογραφίες.
2. Βρες το `FOLDER_ID` από τον σύνδεσμο `https://drive.google.com/drive/folders/FOLDER_ID`.
3. Στο Google Cloud ενεργοποίησε το **Google Drive API** και δημιούργησε API key με **HTTP referrer restrictions** μόνο για `https://pagkalosg.github.io/*` και **API restriction** μόνο για Google Drive API. Το key θα είναι ορατό στα στατικά αρχεία του GitHub, άρα δεν πρέπει να είναι γενικού σκοπού ή ανεξέλεγκτο.
4. Άνοιξε το `data/drive-config.json` και συμπλήρωσε:

```json
{
  "enabled": true,
  "folderId": "FOLDER_ID",
  "apiKey": "YOUR_RESTRICTED_GOOGLE_CLOUD_API_KEY"
}
```

5. Πρόσθεσε απλώς φωτογραφίες στον κοινόχρηστο φάκελο Drive. Το Ημερολόγιο τις ανακτά με το επίσημο Drive API (μέχρι 10 σελίδες × 1.000 αρχεία) και τις εμφανίζει σε όλους χωρίς να ενημερώνεις αρχείο λίστας εικόνων. Η επαναφόρτωση γίνεται από «Ανανέωση κοινών δεδομένων».

Οι εικόνες θα εμφανίζονται μόνο αν είναι δημόσια προσβάσιμες και επιτρέπεται το αίτημα από το Google Drive. Δεν απαιτείται σύνδεση Google από τους παίκτες. Αν το API αποτύχει, η εφαρμογή χρησιμοποιεί την εναλλακτική λίστα `data/campaign-images.json` από το GitHub. Αυτή η σύνδεση δεν μπορεί να λειτουργήσει με **ιδιωτικό** Drive χωρίς ξεχωριστή ασφαλή OAuth/backend υλοποίηση.

Μπορείς να επιλέγεις εικόνες Drive μέσα σε προσωπικά ή κοινά sessions (οι αλλαγές των κοινών καταχωρίσεων παραμένουν τοπικές). Για να αναφέρεται απευθείας μία εικόνα από το `data/sessions.json`, βάλε στο `images` την τιμή `"drive:FILE_ID"` του δημόσιου αρχείου (χωρίς να αντιγράφεις URL). Για την αρχική κοινή συλλογή αρκεί να προσθέσεις τις φωτογραφίες στον φάκελο.

## Weapon Mastery & καταστάσεις όπλων (v2.1.2)

Στον **Εξοπλισμό**, πάτησε ☆/★ δίπλα σε ένα όπλο για να ορίσεις ή να αφαιρέσεις **Weapon Mastery**. Στον Fighter επιπέδου 3 μπορείς να επιλέξεις έως 3 διαφορετικά είδη όπλων. Αν οι επιλογές είναι λιγότερες από 3, εμφανίζεται προειδοποίηση στην **Επισκόπηση**. Μπορείς επίσης να επιλέξεις νόμιμο τύπο όπλου που δεν υπάρχει στο inventory. Δεν έχει γίνει αυθαίρετη επιλογή για τον Borruk. Το Fighting Style προβάλλει το ήδη επιλεγμένο **Protection** χωρίς ξεχωριστή δεύτερη καταχώριση. Ο Borruk έχει όλα τα Resourceful, Skillful και Versatile (σύμφωνα με Human 2024). Το Student of War είναι ικανότητα του Battle Master στο level 3.

## Export σε template

Προς το παρόν το Export παραμένει **ανεπίσημο εκτυπώσιμο φύλλο**. Ένα δικό σου DOCX θα βοηθούσε στον οπτικό σχεδιασμό ενός προσαρμοσμένου φύλλου. Για να παράγουμε όμως *το επίσημο φύλλο 2024*, προτιμάται το αυθεντικό fillable PDF 2024 και συμπλήρωση των πεδίων με αντιστοίχιση από τα δεδομένα. Δεν παρουσιάζουμε DOCX/PDF δικής μας διάταξης ως επίσημο έντυπο.

**Έλεγχος χαρακτήρων:** Δες επίσης το `RULES_AUDIT_EL.md` για τις αλλαγές της Luna και του Ammantyl και τις εκκρεμείς επιλογές του Borruk.


## Τελευταίες αλλαγές v2.1.2

- Το πλήρες πακέτο **συνενώνει** τη v2.1 με το ενημερωμένο `app.js` της v2.1.1. Έγινε αλλαγή του `version.json` και του service-worker cache για σωστή ενημέρωση της PWA.
- Στον Εξοπλισμό εμφανίζεται **☆/★** για Weapon Mastery. Δεν υπάρχουν προεπιλεγμένα όπλα στον Borruk. Η Επισκόπηση προειδοποιεί μέχρι να συμπληρωθούν τα 3.
- Στον Εξοπλισμό κάθε όπλο μπορεί να είναι κανονικό, φθαρμένο, σπασμένο, δηλητηριασμένο, χαμένο, κλεμμένο, κατεστραμμένο ή άλλη κατάσταση, με προαιρετική σημείωση. Η κατάστασή του φαίνεται και στη Μάχη. Δεν εφαρμόζονται αυτομάτως μη τεκμηριωμένες ποινές.
- Το Drive **δεν είναι ρυθμισμένο** στο ZIP: στο `data/drive-config.json` το `enabled` παραμένει `false`. Θα χρειαστεί δημόσιος φάκελος + περιορισμένο Google Drive API key. Οι παίκτες δεν χρειάζονται Google login, αλλά ο φάκελος πρέπει να είναι δημόσια αναγνώσιμος.
- Οι Ability Scores Borruk, Luna και Ammantyl **δεν έχουν αυξηθεί αυθαίρετα**. Επειδή υπάρχουν ενδείξεις ότι ίσως δεν εφαρμόστηκαν τα bonuses Soldier / Entertainer / Noble, απαιτείται πρώτα έλεγχος από τον DM. Το Human 2024 δεν δίνει +1 σε όλα τα χαρακτηριστικά.
- Παραμένουν **εκκρεμότητες**: πλήρης υποστήριξη κανόνων για όλα τα classes, ολοκληρωμένη γλωσσική επιμέλεια σε παλαιότερα dialogs, εξαγωγή σε αυθεντικό επίσημο PDF 2024. Η τωρινή εξαγωγή είναι ανεπίσημη εκτυπώσιμη μορφή.
- Δεν υπάρχουν προσβάσιμες εντολές για ψηφιακές ρίψεις ζαριών. Χρησιμοποίησε τα πραγματικά ζάρια με τις οδηγίες της Μάχης.

### Προσοχή στα τοπικά δεδομένα

Η εγκατάσταση **δεν αντικαθιστά** ήδη αποθηκευμένους χαρακτήρες από το `localStorage`. Πριν κάνεις `Load Party Demo` ή εισαγωγή JSON, κράτησε **Export JSON backup**. Οι προσωπικές εικόνες και αλλαγές στο Ημερολόγιο αποθηκεύονται τοπικά και δεν ανεβαίνουν στο GitHub αυτόματα.
