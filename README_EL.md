# D&D Atlas v2.0 — Οδηγίες για GitHub Pages

Το πακέτο περιέχει **ολόκληρη τη στατική εφαρμογή** και όχι μόνο ένα mockup. Οι έξι καρτέλες είναι Επισκόπηση, Χαρακτήρας, Μάχη, Εξοπλισμός, Ημερολόγιο και Βιβλιοθήκη. Μοναδικό ruleset: **D&D 5e (2024)**.

## Ανέβασμα

1. Πάρε **αντίγραφο JSON** των χαρακτήρων σου μέσα από την τωρινή εφαρμογή και κράτησε αντίγραφο του repository σου.
2. Αποσυμπίεσε το ZIP. Ανέβασε **όλα** τα περιεχόμενά του στη **ρίζα** του repository `dndatlas` (όχι μέσα σε νέο υποφάκελο).
3. Κάνε commit. Αν χρειάζεται, ενεργοποίησε **Settings → Pages → Deploy from branch → main / root**.
4. Άνοιξε `https://pagkalosg.github.io/dndatlas/`. Αν βλέπεις παλαιά έκδοση λόγω PWA, κάνε ανανέωση ή χρησιμοποίησε την επιλογή ενημέρωσης από τις Ρυθμίσεις.
5. Το `demo-party.json` περιέχει τους Borruk, Luna και Ammantyl. Στην πρώτη επίσκεψη χωρίς τοπικούς χαρακτήρες φορτώνεται αυτόματα εφόσον είναι διαθέσιμο. **Δεν αντικαθιστά** υπάρχοντες χαρακτήρες στον browser.

## Εικόνα χαρακτήρα

Από την **Επισκόπηση**, πάτησε την εικόνα. Επίλεξε αρχείο αν δεν υπάρχει, μετακίνησέ το μέσα στο κάδρο με ποντίκι ή δάχτυλο, άλλαξε τη μεγέθυνση από 100% έως 300%, και πάτησε **Αποθήκευση θέσης**. Η αλλαγή εφαρμόζεται **μόνο στην Επισκόπηση**. Δεν αλλοιώνεται η αρχική αποθηκευμένη φωτογραφία.

## Κοινά sessions και εικόνες από GitHub

### 1. Πρόσθεσε εικόνες

Ανέβασε εικόνες JPG, PNG, WebP ή GIF στον φάκελο `assets/campaign/`.

### 2. Ενημέρωσε τη λίστα εικόνων

Στο `data/campaign-images.json` πρόσθεσε:

```json
{
  "schema": 1,
  "images": [
    {"id":"old-map","title":"Χάρτης κάστρου","path":"assets/campaign/castle-map.jpg"},
    {"id":"battle","title":"Μάχη 1","path":"assets/campaign/battle-01.png"}
  ]
}
```

### 3. Πρόσθεσε το κοινό session

Στο `data/sessions.json`:

```json
{
  "schema": 1,
  "campaign": "Our Campaign",
  "sessions": [
    {
      "id": "session-01",
      "title": "Πρώτη συνεδρία",
      "date": "2026-10-17",
      "text": "Εδώ βάζω τι έγινε στη συνεδρία.",
      "images": ["assets/campaign/castle-map.jpg", "assets/campaign/battle-01.png"]
    }
  ]
}
```

Οι κοινές εικόνες εμφανίζονται σε **όλους** μετά το GitHub deployment. Το GitHub Pages δεν προσφέρει αυτόματα τη λίστα αρχείων ενός φακέλου: για τη συλλογή εικόνων πρέπει να ενημερώνεις το `campaign-images.json`.

Κάθε παίκτης μπορεί να προσθέσει προσωπικό session ή να τροποποιήσει/κρύψει κοινό session **μόνο στη δική του συσκευή**. Οι προσωπικές μεταβολές εξάγονται επίσης στο JSON backup. Δεν αλλάζει το αρχικό `sessions.json` στο GitHub. Η προσθήκη φωτογραφίας από συσκευή παραμένει τοπική μέχρι να ανεβάσεις το αρχείο στο GitHub.

## Σημαντικές διευκρινίσεις

- Στη **Μάχη**, τα ξόρκια εμφανίζονται μόνο σε χαρακτήρες με καταχωρισμένα ξόρκια, ενώ οι πολεμικοί ελιγμοί σε χαρακτήρες με τη σχετική δυνατότητα. Υπάρχει επιλογή «Ξόρκια μάχης / Όλα τα ξόρκια μου».
- Υπάρχουν αναλυτικές επεξηγήσεις για το πώς γίνονται οι επιθέσεις με πραγματικά ζάρια, **χωρίς ψηφιακό dice roller**.
- Ο Builder ανοίγει με το **+ Νέος χαρακτήρας**, όχι ως ξεχωριστή καρτέλα. Πλήρης αυτόματος έλεγχος κανόνων υπάρχει αυτή τη στιγμή κυρίως για Human / Fighter / Soldier επιπέδων 1–3. Τα υπόλοιπα χρειάζονται τεκμηριωμένο έλεγχο DM. Οι εισαγόμενοι χαρακτήρες μπορεί να περιέχουν εκκρεμότητες.
- Το PDF export προσφέρει προς το παρόν **εκτυπώσιμο φύλλο συμβατό με τους κανόνες 2024**, με αποθήκευση από τον browser ως PDF. **Δεν γεμίζει ακόμη το πραγματικό επίσημο PDF template της Wizards**.
- Οι περισσότερες οθόνες έχουν διεπαφή ΕΛ/EN. Ορισμένα προχωρημένα παλαιότερα παράθυρα ή ελεύθερες περιγραφές δεδομένων ενδέχεται να έχουν κείμενο διαφορετικής γλώσσας.
- Τα δεδομένα της συσκευής αποθηκεύονται τοπικά. Μην εκκαθαρίζεις τα δεδομένα ιστότοπου χωρίς **Export JSON backup**.

Δες και το αγγλικό `README.md` για επιπλέον τεχνικές λεπτομέρειες.
