# D&D Atlas v3.1.3 — Διόρθωση επίσημου Character Sheet 2024

Αντικατάστησε τα **πέντε αρχεία** `app.js`, `pdf-export.js`, `index.html`, `sw.js` και `version.json` στη ρίζα του GitHub repository.

Διορθώνει και συμπληρώνει όλα τα skill modifiers και saving throw modifiers, τα proficiency checkboxes, το Heroic Inspiration, τα Death Saves, τις σημειώσεις των όπλων, καθώς και τα πραγματικά attack bonus και damage σύμφωνα με τους υπολογισμούς της εφαρμογής. Διατηρεί το επίσημο PDF επεξεργάσιμο.

**Εκκρεμότητες**: Δεν συμπληρώνονται ακόμη όλες οι στήλες ξορκιών, οι spell slots, coins, equipment training ή όλες οι λεπτομέρειες class/subclass. Δεν γίνεται αυτόματη μεταφορά όλων των μεγάλων περιγραφών και το πρότυπο υποστηρίζει λατινικούς χαρακτήρες. Χρειάζεται οπτική επιβεβαίωση μετά την εξαγωγή. Εάν έχεις παράδειγμα εξαγόμενου PDF με λανθασμένο περιεχόμενο, στείλ' το για εξαντλητική διόρθωση των υπόλοιπων πεδίων.

Αυτή είναι **διορθωτική ενημέρωση**, όχι πλήρες ZIP της εφαρμογής· όλες οι άλλες λειτουργίες παραμένουν όπως στη v3.1.2. Αυξήθηκε το PWA cache version σε 3.1.3 για να φορτωθούν τα νέα scripts.
